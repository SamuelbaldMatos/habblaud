# Receitas do Estúdio de Código — Habblaud

Receitas são roteiros prontos para tarefas comuns de engenharia, adaptados
ao conjunto de ferramentas do Estúdio de Código do Habblaud.

## Origem

Adaptadas dos prompts do **vibe-coding-toolkit** de Matheus Gomes:
<https://github.com/soumatheusgomes/vibe-coding-toolkit>
Licença original: **MIT** — uso, cópia e modificação livres com atribuição.

## Como usar

Abra uma tarefa no Estúdio, cole o roteiro da receita escolhida e substitua
`{{workspace}}` pelo caminho real do projeto. Siga os passos numerados.

## Como criar uma receita nova

1. Crie `shared/recipes/<id>.md` com o frontmatter abaixo.
2. Escreva o roteiro em passos numerados usando **apenas** as ferramentas
   disponíveis no Estúdio (veja lista no cabeçalho de cada receita).
3. Termine com "Entrega:" descrevendo o que o usuário recebe.
4. Mantenha até ~45 linhas de roteiro; tarefas longas viram várias receitas.
